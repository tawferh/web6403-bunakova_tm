### Лабораторная работа №2.
**Задание:** разработать многостраничный web-сайт на произвольную тему с использованием HTML и CSS.\
**Тема:** сайт кофейни «Пенка».

#### Структура проекта
```
lab2/
├── index.html — главная: первый экран, преимущества, фотографии, хит сезона
├── menu.html — меню: таблицы напитков и десертов
├── about.html — о кофейне: история, принципы
├── contacts.html — адрес, телефон, таблица часов работы
├── css/
│   └── style.css — общий подключаемый файл стилей
└── images/ — логотип, иконки и фотографии
```

#### Запуск
Открыть `lab2/index.html` в браузере.

### Лабораторная работа №3.
**Задание:** написать набор функций на языке JavaScript, реализующих требуемый функционал, и загрузить проект в репозиторий.\
**Тема:** основы JavaScript.\
**Каркас проекта:** https://github.com/teach-kirshdv/js-tasks

#### Структура проекта
```
lab3/
├── src/
│   ├── core.js — реализация требуемого набора функций
│   └── core.spec.js — автоматические тесты для проверки корректности работы функций
├── package.json — конфигурация проекта и используемые зависимости
├── .gitignore — файлы и папки, исключённые из репозитория (node_modules)
└── .prettierrc — настройки форматирования кода
```

#### Инструкция по запуску:
1. Перейти в каталог лабораторной работы:
   ```
   cd lab3
   ```
2. Установить зависимости:
   ```
   npm install
   ```
3. Запустить модульные тесты:
   ```
   npm test
   ```
