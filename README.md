### Лабораторная работа №2.
**Задание:** разработать многостраничный web-сайт на произвольную тему с использованием HTML и CSS.\
**Тема:** сайт кофейни «Пенка».

#### Структура проекта
```
lab2/
├── index.html — главная: первый экран, преимущества, фотографии, хит сезона
├── menu.html — меню: таблицы напитков и десертов
├── about.html — о кофейне: история, принципы
├── contacts.html — адрес, телефон, таблица часов работы
├── css/
│   └── style.css — общий подключаемый файл стилей
└── images/ — логотип, иконки и фотографии
```

#### Запуск
Открыть `lab2/index.html` в браузере.

### Лабораторная работа №3.
**Задание:** написать набор функций на языке JavaScript, реализующих требуемый функционал, и загрузить проект в репозиторий.\
**Тема:** основы JavaScript.\
**Каркас проекта:** https://github.com/teach-kirshdv/js-tasks

#### Структура проекта
```
lab3/
├── src/
│   ├── core.js — реализация требуемого набора функций
│   └── core.spec.js — автоматические тесты для проверки корректности работы функций
├── package.json — конфигурация проекта и используемые зависимости
├── .gitignore — файлы и папки, исключённые из репозитория (node_modules)
└── .prettierrc — настройки форматирования кода
```

#### Инструкция по запуску:
1. Перейти в каталог лабораторной работы:
   ```
   cd lab3
   ```
2. Установить зависимости:
   ```
   npm install
   ```
3. Запустить модульные тесты:
   ```
   npm test
   ```

### Лабораторная работа №4.
**Задание:** в качестве основы скопировать web-сайт из лабораторной работы №2, модернизировать его с использованием технологий HTML, CSS и JavaScript и загрузить проект в репозиторий.\
**Тема:** изучение современного CSS и основ ООП на JavaScript.\

#### Структура проекта
```
lab4/
├── index.html — главная страница
├── menu.html — меню
├── about.html — о кофейне
├── contacts.html — адрес, телефон, часы работы
├── booking.html — страница с формой
├── css/
│   └── style.css — общий подключаемый файл стилей
├── js/
│   └── main.js — класс регистрации и обработчик отправки формы
└── images/ — логотип, иконки и фотографии
```

#### Требования к web-сайту:
1.	Вёрстка с помощью Flexbox – 1 страница.
2.	Вёрстка с помощью Grid – 1 страница.
3.	Задание всех цветов только с помощью переменных в CSS.
4.	Реализация анимации (красивой!) с помощью CSS – 1шт.
5.	Реализация страницы с формой, включающей не менее 3 различных типов полей (например, страница авторизации с вводом логина, пароля и галочкой-согласием на обработку данных) и кнопку отправки данных на сервер.
6.	Создание класса, содержащего конструктор и метод форматированного вывода на консоль. При нажатии на кнопку отправки данных на сервер должен создаваться объект, хранящий введённые данные, после чего вызывается метод вывода на консоль.
7.	Бонус: использовать методологию БЭМ
