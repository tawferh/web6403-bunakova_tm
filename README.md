### Лабораторная работа №2. Основы HTML и CSS

**Задание:** разработать многостраничный web-сайт на произвольную тему с использованием HTML и CSS.\
**Тема:** сайт кофейни «Пенка».
### Структура проекта
```
lab2/
├── index.html — главная: первый экран, преимущества, хит сезона
├── menu.html — меню: таблицы напитков и десертов
├── about.html — о кофейне: история, принципы, иллюстрация фасада
├── contacts.html — адрес, ссылки, таблица часов работы
├── css/
│   └── style.css — общий подключаемый файл стилей
└── images/ — логотип и иллюстрации
```
### Запуск
Открыть `lab2/index.html` в браузере.
